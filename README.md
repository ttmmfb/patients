# Учёт пациентов и сводная статистика (Tkinter + Matplotlib)

Графическое приложение на Python для ведения базы данных пациентов, автоматического расчёта индекса массы тела (ИМТ) и визуализации сводной статистики.

## Возможности
- **Таблица пациентов (`ttk.Treeview`):** отображение ФИО, возраста, пола, роста, веса и автоматически рассчитанного ИМТ с вертикальной прокруткой.
- **Генерация и хранение данных:** при первом запуске автоматически генерирует 20 тестовых записей с помощью библиотеки `Faker` и сохраняет базу в файл `patients.json`.
- **Управление записями (`Toplevel`):** добавление новых пациентов, редактирование выбранной записи и удаление с подтверждением через модальное диалоговое окно.
- **Сводная статистика (`Matplotlib`):** построение 4 графиков на одном полотне (распределение по полу, распределение по возрасту, распределение ИМТ с учётом пола и зависимость ИМТ от возраста).

## Установка и запуск

1. Клонируйте репозиторий или скачайте файлы проекта:
   ```bash
   git clone https://github.com/ttmmfb/patients
   cd patients
   ```

2. Установите необходимые внешние библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python forma.py
   ```
